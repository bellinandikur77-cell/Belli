## 🔌 Where Hardware Meets Software

ECE gives me an edge I want to use: I don't treat the machine as a black box.

```text
   Sensor / Signal
         │
         ▼
   ADC / Microcontroller ──►  Embedded C firmware
         │
         ▼
   Communication (UART · I2C · SPI · Wi-Fi/BLE)
         │
         ▼
   Backend / Database  ──►  Web Dashboard
         │
         ▼
       Insight 💡
```

**Areas that fascinate me**

- 🧩 **Embedded systems**: microcontrollers, peripherals, interrupts, real-time behavior
- 📡 **Communication systems**: protocols, signals, modulation, networking basics
- 🧮 **Digital electronics**: logic design, HDL, FPGA-style thinking
- 🌍 **IoT**: connecting physical devices to web apps and cloud
- 🔧 **Systems programming**: C, memory, pointers, how software really runs
